# SB-79 Analysis

The goal of this repo is to provide the tools and framework for anyone to go to any city they want and create a folium map of the parcels that will be upzoned

Eventually the hope is that this will be used to compare SB-79 Capacity to Local Planning capacity to see whether or not a local plan is compliant
